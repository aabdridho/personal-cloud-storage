# API reference

Interactive documentation (Swagger UI) is generated by FastAPI at **`/docs`**, and the raw OpenAPI 3.1 schema at **`/openapi.json`**. This page explains the rules behind the endpoints.

All endpoints except `/health` and `/auth/login` require `Authorization: Bearer <token>`. Request and response bodies are JSON, except file uploads (`multipart/form-data`) and login (`application/x-www-form-urlencoded`, the OAuth2 password flow). Timestamps are ISO 8601 in UTC.

## Authentication

| Method | Path | Body | Success |
|---|---|---|---|
| `POST` | `/auth/login` | form: `username`, `password` | `200 {"access_token", "token_type": "bearer"}` |
| `GET` | `/auth/me` | — | `200 UserInfo` |
| `GET` | `/auth/me/storage` | — | `200 {"used_bytes", "quota_bytes", "file_count", "used_percent"}` |

A wrong username and a wrong password return the same `401 "Username atau password salah"`, and an unknown username still runs one Argon2 verification against a dummy hash, so response time does not reveal which usernames exist.

Tokens are HS256 JWTs with `sub` (user id) and `exp` (60 minutes). The payload is signed, not encrypted. Every request re-loads the user and rejects the token if the account has been deactivated, so deactivation takes effect immediately even though JWTs cannot be revoked.

```bash
TOKEN=$(curl -sk -X POST https://localhost/auth/login \
  --data-urlencode "username=alice" --data-urlencode "password=..." \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["access_token"])')
```

## Users (admin only)

The whole router depends on `get_current_admin`, so no endpoint in it can be left unprotected by accident.

| Method | Path | Body | Success | Errors |
|---|---|---|---|---|
| `GET` | `/users` | — | `200 [UserInfo]` | `401`, `403` |
| `POST` | `/users` | `{"username", "password", "is_admin"?, "quota_bytes"?}` | `201 UserInfo` | `409` username taken, `422` validation |
| `PATCH` | `/users/{id}` | `{"is_active"?, "quota_bytes"?}` | `200 UserInfo` | `404`, `400` admin deactivating themself |

Validation: username 3–50 characters from `[a-zA-Z0-9_.-]`, password 8–128 characters, quota ≥ 0. `UserInfo` never includes the password hash.

There is deliberately no public registration. The first admin is created from the command line (`create_user.py`), and the admin creates accounts for family members.

## Folders

| Method | Path | Body | Success | Errors |
|---|---|---|---|---|
| `POST` | `/folders` | `{"name", "is_shared"?}` | `201 FolderInfo` | `409` name taken |
| `GET` | `/folders` | — | `200 [FolderInfo]`: own folders and every shared folder, shared first | — |
| `PATCH` | `/folders/{id}` | `{"name"?, "is_shared"?}` | `200 FolderInfo` | `404`, `403` not the creator, `409` name taken or other members' files inside when un-sharing |
| `DELETE` | `/folders/{id}` | — | `204` | `404`, `403`, `409` folder not empty |

Folders are one level deep. Names cannot contain `/` or `\`.

## Files

| Method | Path | Input | Success | Errors |
|---|---|---|---|---|
| `POST` | `/files` | multipart `file`, optional form field `folder_id` | `201 FileInfo` | `400` bad name, `404` folder not accessible, `409` name taken, `413` too large, `507` quota exceeded |
| `GET` | `/files` | query: `folder_id`, `q`, `content_type`, `limit` (1–200, default 50), `offset` | `200 [FileInfo]`, newest first | `404` folder not accessible |
| `PATCH` | `/files/{id}` | `{"filename"?, "folder_id"?}` | `200 FileInfo` | `404`, `403` not the uploader, `409`, `422` |
| `GET` | `/files/{id}` | — | `307` redirect to a 5-minute presigned URL | `404` |
| `GET` | `/files/{id}/link` | query: `expires` seconds (60–604800, default 3600) | `200 {"url", "expires_in", "expires_at"}` | `404`, `422` |
| `DELETE` | `/files/{id}` | — | `204` | `404`, `403` |

Notes:

- **`GET /files` without `folder_id`** lists all of *your* files everywhere. **With `folder_id`** it lists that folder, including other members' files when the folder is shared.
- **`q`** is a case-insensitive substring search. `%` and `_` are escaped, so searching for `%` does not match everything.
- **Moving a file:** `{"folder_id": 3}` moves it into folder 3, `{"folder_id": null}` moves it to the root, and leaving `folder_id` out of the body leaves it where it is. The API tells these apart with Pydantic's `model_fields_set`.
- **Renaming or moving never touches storage.** Only the database row changes.
- **Ordering** is `uploaded_at DESC, id DESC`. The `id` tie-breaker keeps pagination stable.

## Access rules

| Action | Private folder / root | Shared folder |
|---|---|---|
| See the folder and list its files | creator | every active user |
| Upload into it | creator | every active user |
| Download a file / create a share link | file's uploader | every active user |
| Rename, move or delete a **file** | file's uploader | file's uploader |
| Rename, (un)share or delete the **folder** | creator | creator |

Quota is always charged to the uploader. The admin role manages accounts and quotas only. It grants **no** access to other members' files.

### 404 or 403?

- **The caller may not know the resource exists → `404`.** Another user's private file looks exactly like a file id that was never created.
- **The caller may see it but not change it → `403`.** For example, a file another member put in a shared folder.

All of these rules live in `permissions.py`, and every router uses the same four helpers, so a new endpoint cannot accidentally apply a different rule.

## Status codes used

| Code | Meaning in this API |
|---|---|
| `200` / `201` / `204` | OK / created / deleted (no body) |
| `301` | Nginx: HTTP redirected to HTTPS |
| `307` | Download redirect to a presigned URL |
| `400` | Invalid file name; admin deactivating themself |
| `401` | Missing, invalid or expired token; inactive account; wrong credentials |
| `403` | Authenticated but not allowed (not admin, not uploader, not folder creator) |
| `404` | Does not exist **or** you may not know it exists |
| `409` | Name conflict; folder not empty; un-sharing a folder that holds others' files |
| `413` | File too large (Nginx returns HTML, the API returns JSON) |
| `422` | Request validation failed (FastAPI/Pydantic, `detail[].loc` points at the field) |
| `507` | Storage quota exceeded |

## Presigned URLs

Download and share links point at `/cloud-storage/<uuid>` with `X-Amz-*` query parameters. Anyone holding the link can download the file until it expires, without logging in. Changing any character of the URL gives `403 SignatureDoesNotMatch`, and an expired link gives `403 AccessDenied: Request has expired`. Links cannot be revoked individually (only by rotating the storage secret), so keep `expires` short. The maximum is 7 days.
